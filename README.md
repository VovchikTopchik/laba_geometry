# Растровая графика

Приложение на Python с использованием Pygame. Программа отображает рабочую область в виде клеточной сетки и позволяет строить отрезки двумя алгоритмами растеризации, а также выполнять заливку связной области.

## Возможности

- Построение отрезков алгоритмом Брезенхэма.
- Построение отрезков алгоритмом DDA.
- Заливка области с помощью алгорима Flood Fill.
- Пошаговая визуализация построения и заливки на клеточной сетке.

## Структура проекта

```text
laba_geometry/
├── main.py          # Точка входа, обработка событий мыши и клавиатуры
├── rasterfill.py    # Отрисовка матрицы, алгоритмы линий и заливки
├── state.py         # Параметры окна, сетки, цвета и матрица
├── main.spec        # Конфигурация PyInstaller
└── requirements.txt # Зависимости проекта
```

## Установка и запуск

### 1. Установите Python

Установите Python 3. Для запуска из терминала команда `python` должна быть доступна в PATH.

### 2. Перейдите в каталог проекта

```bash
cd laba_geometry
```

### 3. (Рекомендуется) Создайте виртуальное окружение

```bash
python -m venv .venv
```

Активация окружения:

**Windows PowerShell**
```powershell
.venv\Scripts\Activate.ps1
```

**Windows cmd**
```cmd
.venv\Scripts\activate.bat
```

**Linux / macOS**
```bash
source .venv/bin/activate
```

### 4. Установите зависимости

```bash
python -m pip install -r requirements.txt
```

### 5. Запустите приложение

```bash
python main.py
```

## Управление

| Действие | Результат |
|---|---|
| Левая кнопка мыши | Переключает состояние клетки. Каждое нажатие также задаёт одну из двух точек: сначала начальную, затем конечную. |
| Правая кнопка мыши | Запускает 4-связную заливку от выбранной клетки. |
| Средняя кнопка мыши | Запускает 8-связную заливку от выбранной клетки. |
| `B` | Строит отрезок между последними заданными точками алгоритмом Брезенхэма. |
| `D` | Строит отрезок между последними заданными точками алгоритмом DDA. |
| `C` | Обнуляет все клетки матрицы. Координаты последних заданных точек при этом не сбрасываются. |
| Закрытие окна | Завершает работу приложения. |

Клики мышью за пределами сетки игнорируются. Для построения отрезка сначала задайте две точки левой кнопкой мыши, затем нажмите `B` или `D`.

## Параметры рабочей области

Текущие значения заданы в `state.py`:

- ширина сетки — **40 клеток**;
- высота сетки — **30 клеток**;
- размер внутренней части клетки — **20 пикселей**;
- толщина линий сетки — **1 пиксель**;
- скорость пошаговой отрисовки задаётся константой `SPEED`.

## Сборка исполняемого файла

В проекте есть конфигурация `main.spec`. Если PyInstaller ещё не установлен, установите его:

```bash
python -m pip install pyinstaller
```

Затем из каталога проекта выполните:

```bash
pyinstaller main.spec
```

Исполняемый файл будет создан в каталоге `dist`.

## Зависимости

Список внешних зависимостей находится в `requirements.txt`. Модуль `collections` входит в стандартную библиотеку Python и отдельно устанавливать его не нужно.
